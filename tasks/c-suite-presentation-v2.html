The Bad

Issues hurting your rankings

Technical SEO Issues Bad

Fixable problems holding you back

⚠️ Sitemap Uses HTTP (Not HTTPS)

All 7 sub-sitemaps reference HTTP URLs. Can cause indexing inconsistencies.

# Current (wrong)
http://www.encore-funding.com/post-sitemap.xml

# Should be
https://www.encore-funding.com/post-sitemap.xml

⚠️ No Schema Markup

Missing: Organization, LocalBusiness, FAQ, Article, BreadcrumbList schemas. Competitors have these.

⚠️ Robots.txt Too Thin

No sitemap reference, no crawl directives for /wp-admin/

⚠️ Meta Description Gaps

Many pages missing explicit meta descriptions. Truncated titles in search results.

⚠️ H1 Tag Inconsistency

Some pages have multiple H1s (Beaver Builder issue). H1s don't always contain keywords.

⚠️ Weak Internal Linking

Blog posts don't link to service pages. No breadcrumb navigation.

⚠️ Multiple Author Sitemaps

Both authors-sitemap.xml AND author-sitemap.xml exist. Crawl budget waste.
