# SECTION 2: THE PROBLEMS

---

## Problem #1: Split Domain Authority

### How Google Sees You

```
encore-funding.com      → Domain Authority: X
gov.encore-funding.com  → Domain Authority: Y (lower, newer)
```

**Every backlink to the subdomain doesn't help the main site.**

If someone links to Eric's GovCon content, that SEO value stays on the subdomain.

### The Fix
Consolidate: `gov.encore-funding.com` → `encore-funding.com/govcon/`

One domain. One authority score. All links benefit everything.
