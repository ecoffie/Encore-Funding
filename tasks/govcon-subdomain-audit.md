# GovCon Subdomain SEO Audit
**Site:** gov.encore-funding.com
**Date:** March 17, 2026
**Prepared by:** GovCon Giants

---

## Executive Summary

Encore Funding launched **gov.encore-funding.com** in October 2024 as a dedicated site for government contractor financing. While the content is solid and the GovCon Giants partnership is working, the subdomain architecture is **diluting SEO authority** that should be consolidated.

**Key Finding:** The subdomain should be migrated to `encore-funding.com/govcon/` to consolidate domain authority.

## The Bad

### 1. Subdomain Architecture (Critical)
**Problem:** Using subdomain instead of subfolder

| Current | Should Be |
|---------|-----------|
| gov.encore-funding.com | encore-funding.com/govcon/ |

**Why This Matters:**
- Subdomains are treated as separate sites by Google
- Backlinks to subdomain don't help main domain
- Domain authority is split between two properties

### 2. No Cross-Linking
- Main site doesn't link to GovCon subdomain prominently
- Subdomain doesn't link to main site resources
- Missing internal linking opportunities

### 3. Thin Content on Some Pages
- Several blog posts under 800 words
- No pillar page for GovCon financing
- Missing comparison content

### 4. No Schema Markup
- Missing Organization schema
- No Article schema on blog posts
- No FAQ schema on educational content
- No BreadcrumbList

---

## The Ugly

### 1. Authority Dilution
| Property | Users | Domain Authority |
|----------|-------|------------------|
| encore-funding.com | 21,280 | Higher (established) |
| gov.encore-funding.com | 6,877 | Lower (newer) |

**Combined:** 28,000+ users could be strengthening ONE domain

### 2. Content Cannibalization
Main site has: `/solutions/funding-options/government-contract-financing/`
Subdomain is: Entire site dedicated to same topic

**Google doesn't know which to rank.** They're competing with each other.

### 3. Partnership Link Waste
- GovCon Giants partnership links go to subdomain
- Eric Coffie content exists on subdomain only
- These backlinks should be helping the main domain

### 4. Keyword Competition
Both domains target:
- "government contract financing"
- "govcon funding"
- "contractor invoice factoring"

Instead of one strong page, there are two weak competitors.

## Recommendations

### Immediate (Week 1-2)

1. **Decision: Migrate or Keep Separate**
   - **Recommendation:** Migrate to `encore-funding.com/govcon/`
   - Set up 301 redirects for all subdomain URLs
   - Preserve all content and URL structure

2. **If Migration Approved:**
   - Map all subdomain URLs to new subfolder paths
   - Update all internal links
   - Notify Google Search Console
   - Monitor for 404s

3. **If Keeping Subdomain:**
   - Add prominent cross-links between sites
   - Implement canonical tags properly
   - Accept reduced SEO efficiency
